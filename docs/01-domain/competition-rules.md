# Competition Rules

## 현재 상태

Cubing Hub에는 competition과 organizer domain이 구현돼 있지 않다. 이 문서는 향후 논의를 위한 권위와 용어 경계만 정의한다.

## 권위 경계

- WCA 공식 대회와 결과는 WCA 규정, delegate, 공식 시스템의 권위를 따른다.
- Cubing Hub가 향후 제공할 online 또는 community competition은 별도 규칙과 비공식 상태를 명확히 표시해야 한다.
- Cubing Hub 내부 결과를 WCA official result로 표현하지 않는다.

## 결정이 필요한 영역

- competition 유형과 참가 자격
- scramble 생성·배포·기밀성
- inspection, timing, penalty, DNF 규칙
- judge와 organizer 역할
- 결과 제출·검증·이의제기
- 부정행위와 제재
- 개인정보, 미성년자, 영상 evidence
- 장애 시 중단·재개·결과 무효 처리

## 참고 원칙

WCA 규정은 현재 버전의 공식 페이지를 링크해 참고하되 내용을 장문 복제하지 않는다. Cubing Hub가 다르게 정한 규칙은 차이를 눈에 띄게 명시한다.

## 비목표

대회 출시 일정, bracket, registration schema, payment, API는 이 문서에서 선설계하지 않는다.
