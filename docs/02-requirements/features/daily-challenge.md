# Daily Challenge

## 상태

후보 기능이며 출시 시점과 우선순위가 정해지지 않았다. 홈의 날짜 고정 scramble은 현재 기능이지만 Daily Challenge의 참여·점수·검증 기능을 뜻하지 않는다.

## 문제 가설

반복 참여 동기와 사용자 간 느슨한 비교를 제공할 수 있다.

## 검증할 사용자

- 매일 짧게 연습하는 사용자
- 친구나 community와 같은 조건으로 도전하고 싶은 사용자

## Open Questions

- challenge가 solve 연습인지 경쟁인지
- 날짜와 timezone, event, scramble 공개 시점
- 재시도와 제출 횟수
- self-reported와 verified 결과 구분
- 부정행위, privacy, moderation
- streak나 reward가 건강한 사용을 돕는지

DB, API, scoring, 일정은 검증 뒤 설계한다.
