# Verified Record

## 상태

후보 기능이다. 현재 Record와 Ranking은 self-reported이며 verified badge나 review workflow가 없다.

## 문제 가설

비공식 online activity에서도 기록의 신뢰 수준을 구분할 필요가 있을 수 있다.

## 후보 사용자

- 성과를 community에 신뢰 있게 공유하려는 사용자
- challenge 또는 competition 결과를 검토하는 운영자

## Open Questions

- 검증할 event와 기록 범위
- video·smart cube·judge 등 evidence
- reviewer 역할과 처리 시간
- 재제출·appeal·제재
- evidence 개인정보와 retention
- WCA official result와의 표시 경계
- 운영 비용을 누가 부담하는지

상세 정책은 [Record Verification](../../01-domain/record-verification.md)에서 먼저 합의한다.
