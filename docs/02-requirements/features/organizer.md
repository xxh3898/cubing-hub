# Organizer

## 상태

Organizer 역할과 도구는 후보이며 B2B 중심성이나 수익모델이 확정되지 않았다.

## 문제 가설

대회·행사 운영자는 참가 관리, 진행, 결과 공유, 공지에서 반복 작업과 현장 실패 위험을 겪을 수 있다.

## 검증할 사용자

- 지역 비공식 대회 운영자
- 공식 대회 주변 도구를 사용하는 organizer
- 브랜드·매장·동아리 행사 담당자

## Open Questions

- 현재 가장 비용이 큰 업무와 사용 중인 도구
- WCA 시스템과 겹치지 않고 보완할 범위
- 현장 offline·network failure 대응
- 권한 위임과 audit
- 참가자 개인정보와 보관 기간
- 지원 SLA와 책임
- 무료·유료·partnership 운영모델

실제 organizer interview 전에는 workflow, role matrix, DB를 확정하지 않는다.
