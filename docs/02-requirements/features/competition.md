# Competition

## 상태

중요한 후보지만 Cubing Hub 전체 정체성이나 우선순위로 확정되지 않았다.

## 문제 가설

공식 대회 밖에서도 참가자가 공정한 조건으로 활동하고 결과를 공유하거나, 지역 행사 정보를 더 쉽게 탐색할 필요가 있을 수 있다.

## 후보 범위

- online challenge 또는 competition
- 지역·비공식 대회 정보와 참가 흐름
- 공식 대회 주변의 준비·결과 탐색 보조

위 범위는 서로 다른 책임과 검증 수준을 가지므로 하나의 기능으로 확정하지 않는다.

## Open Questions

- 공식·비공식·online 중 어느 문제를 우선 검증할지
- scramble, judge, timing, evidence 권위
- registration과 참가자 개인정보
- 장애·분쟁·결과 정정
- WCA, WCA Live와의 관계
- organizer 없이도 가능한 최소 경험

DB, endpoint, bracket, payment는 아직 설계하지 않는다.
