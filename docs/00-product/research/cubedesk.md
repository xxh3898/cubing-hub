# CubeDesk Research

## 서비스 개요

CubeDesk는 web timer에서 출발해 multiplayer와 community 기능을 포함하는 cubing web app으로 확장한 서비스다.

## 핵심 사용자

현대적인 timer UX와 친구·leaderboard·1v1 같은 social practice를 함께 원하는 큐버다.

## 해결하는 문제

개인 연습이 고립되지 않고 identity와 competition으로 이어지도록 한다.

## 핵심 기능

- timer와 solve data 설정
- keyboard, StackMat, smart cube 입력
- inspection과 custom cube type
- 1v1, leaderboard, friending
- web app 기반 update

## Core Loop

solve 측정·저장 → 개인 성과 확인 → 친구·leaderboard·1v1 참여 → 다시 연습한다.

## 강점

- 확인된 사실: timer와 social·multiplayer 기능을 한 제품 방향으로 설명한다
- 해석: practice에서 social interaction으로 넘어가는 경로가 분명하다

## 약점

- 확인된 사실: 공개 약관에는 paid subscription 가능성이 있지만 현재 가격·유료 범위는 확인되지 않았다
- 추론: 광범위한 community 비전은 moderation과 active user density에 의존할 수 있다

## 수익모델 또는 운영모델

이용약관은 paid subscription 가능성을 포함한다. 조사일 현재 공식 공개 페이지에서 실제 가격과 유료 feature 범위는 확인하지 못했다.

## Cubing Hub와 겹치는 영역

timer, solve history, ranking·leaderboard, profile, community 방향이 겹친다.

## Cubing Hub가 참고할 점

- timer에서 identity와 social activity로 이어지는 연결
- input·inspection preference를 명확히 설정하는 UX
- web app update와 data continuity 설명

## Cubing Hub가 따라하지 않을 점

Chess.com형 플랫폼이라는 비전을 근거 없이 복제하거나, multiplayer를 핵심 기능으로 먼저 확정하지 않는다.

## 차별화 가능 영역

한국 사용자와 지역 활동, learning·community·운영 feedback을 기존 V1 흐름에서 연결할 수 있는지 검증한다.

## 확인된 사실

About, Timer Settings, Terms에 공개된 설명만 사실로 사용했다.

## 추론/가설

social feature의 실제 활성도, retention, moderation 비용은 공개 페이지로 판단할 수 없으므로 사용자 관찰이 필요하다.
