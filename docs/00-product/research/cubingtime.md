# CubingTime Research

## 서비스 개요

CubingTime은 timer, online room, weekly contest, profile·friends, news·message를 결합한 cubing social service다.

## 핵심 사용자

실시간 또는 반복 competition과 다른 큐버와의 소통을 원하는 사용자다.

## 해결하는 문제

개인 연습을 shared room, contest, social identity로 연결한다.

## 핵심 기능

- timer
- WCA event별 online rooms
- weekly contests
- profile와 friends
- news와 messages
- WCA competition 정보 목록

## Core Loop

timer 또는 room 진입 → 같은 event solve 제출 → room·contest 결과와 대화 확인 → profile·친구 관계로 재참여한다.

## 강점

- 확인된 사실: synchronous room과 contest, social 기능이 한 서비스에 있다
- 해석: 연습과 실시간 참여 사이의 전환을 관찰하기 좋은 사례다

## 약점

- 확인된 사실: 공개 news에는 오래된 항목이 있고 competition 목록의 최신 유지 상태는 별도 확인이 필요하다
- 추론: 화면에 존재하는 기능과 실제 active community 규모가 다를 수 있다

## 수익모델 또는 운영모델

사이트는 cccstore.ru project라고 표시한다. 조사일 현재 명확한 가격과 수익 배분은 공식 공개 페이지에서 확인하지 못했다.

## Cubing Hub와 겹치는 영역

timer, ranking·contest, profile, community·message 영역이 겹친다.

## Cubing Hub가 참고할 점

- 동일 조건에서 즉시 함께 푸는 room 경험
- weekly cadence가 반복 참여를 만드는 방식
- 결과와 대화를 같은 context에 두는 구조

## Cubing Hub가 따라하지 않을 점

active user density와 moderation 근거 없이 실시간 room을 먼저 구현하지 않는다.

## 차별화 가능 영역

한국어 community와 offline·지역 활동 연결, 검증 수준이 명확한 challenge를 조사할 수 있다.

## 확인된 사실

공식 home, rooms, site news에 표시된 기능과 운영 표기를 사용했다.

## 추론/가설

실시간 기능보다 비동기 daily challenge가 초기 사용자 밀도에 더 적합한지는 별도 검증 사항이다.
