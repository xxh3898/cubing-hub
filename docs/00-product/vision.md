# Vision

## 문서 상태

제품 positioning, Primary User, 핵심 문제와 Core Loop는 2026-08-10 사용자 결정으로 확정됐다. 이 문서는 현재 제품 방향의 기준으로 사용한다. 미래 기능의 상세 범위·정책은 각 draft 문서와 [PRD](prd.md)의 gate를 따른다.

## Product Positioning

Cubing Hub는 큐버의 연습, 기록, 성장, 경쟁 활동을 하나의 흐름으로 연결하는 Cuber-first 큐빙 활동 플랫폼이다.

## Primary User

일상적으로 큐브를 반복 연습하며 기록 단축과 성장에 관심 있는 큐버를 우선한다.

Organizer, Brand, Partner는 현재 Primary User가 아니라 장기 ecosystem 확장 영역이다.

## 핵심 문제와 가치

solve가 단순 기록으로 쌓이고 끝나면 연습 결과가 성장·비교·참여·장기 활동 이력으로 이어지지 않는다.

Cubing Hub는 solve를 단순 기록으로 끝내지 않고 성장·비교·참여·장기 활동 이력으로 연결한다.

## Core Loop

```text
Practice
→ Record
→ Improve
→ Participate
→ Profile
→ Practice
```

기존 V1의 인증, timer·record, ranking, learning, community, profile, feedback·운영 기능은 삭제 대상이 아니라 이 흐름 안에서 강화하고 연결할 기반이다.

## 제품 경계

- Competition은 현재 제품 전체 정체성이 아니라 advanced participation 영역이다.
- Daily Challenge는 Participation 가치를 검증할 미래 후보이며 상세 규칙은 확정하지 않았다.
- Verified Record는 측정 방식만으로 결정하지 않고 evidence와 verification process를 함께 다룬다.
- WCA Official Result는 외부 WCA Source of Truth의 결과이며 Cubing Hub 내부 기록과 구분한다.
- Smart Timer와 Smart Cube는 입력·분석·evidence 후보지만 현재 제품의 필수 전제가 아니다.
- 서비스 운영 주체는 Cubing Hub에 유지하며 독립 운영과 사용자 신뢰를 우선한다.

## 제품 원칙

- Cuber의 반복 연습 흐름을 먼저 개선한다.
- 현재 기능과 미래 후보, 확인된 사실과 가설을 분리한다.
- Practice 여부, Input Method, Verification Level을 같은 개념으로 취급하지 않는다.
- 신뢰·개인정보·운영 부담이 큰 기능은 사용자 검증과 정책 결정을 먼저 거친다.
- 공식 WCA 권위와 Cubing Hub의 self-operated activity를 혼동하지 않는다.

## 제품 방향을 바꾸지 않는 검증 영역

- 한국 큐버가 도구 사이의 단절을 얼마나 강한 문제로 느끼는가
- 어떤 성장 지표와 Profile 표현이 반복 연습에 실질적인 도움을 주는가
- Daily Challenge가 건강한 반복 참여를 만드는가
- Verified Record, Competition, Organizer에 실제 수요와 운영 가능성이 있는가
- Partner·Brand 협력이 Cuber 가치와 독립 운영 원칙을 함께 만족시키는가

이 항목은 future phase 진입 근거를 확인하는 영역이며, 현재 positioning, Primary User, 핵심 가치와 Core Loop를 미확정 상태로 되돌리지 않는다.

조사 사실과 미검증 가설은 [Market Validation](market-validation.md), 현재 구현 범위는 [PRD](prd.md), 단계 순서는 [Roadmap](roadmap.md)에서 관리한다.
